01 · AI application

Study Buddy: chat with your course material

Upload lecture PDFs, ask questions in Hebrew or English, and get answers grounded in the material with page-level citations. Generates practice exams with one click.

How a question is answered

PDF→clean & chunk by page→multilingual embeddings→Chroma
question→top-k search→Claude→answer with [1][2] citations
  • Retrieval-Augmented Generation (RAG) system with a FastAPI backend and a right-to-left web interface.
  • Hebrew questions can match English notes, because both languages share one embedding space.
  • Switches between sending the whole document (for broad questions like "summarize this file") and similarity search for large material.
  • Quiz mode uses structured JSON output, so every generated exam is valid and each question points back to its page.
  • Testing on real lectures found that slide decks were half noise; a cleaning step cut one lecture from 32K to 16K characters without losing content. Also found and fixed a startup race condition, with a regression test.
  • pytest suite with a fake embedder and fake LLM, running in CI on every push.

  • Generated realistic member records with an open-source LLM, assigned churn with rules in Python, and ran data quality checks.
  • Analyzed churn with pandas and SQL: members visiting fewer than 7 times a month churned at 46%, vs. 33% for everyone else.
  • Students had the highest churn even though no rule targeted them. 15 of the 26 students are in Holon, and a SQL check showed part of the student effect is really a branch effect.
  • Documented the limits honestly: synthetic data and small groups. Next step is rerunning on 1,000 members.

03 · LLM tool

Synthetic Data Generator

Type a request like "Give me 10 fake customers with name, age and city" and an open-source model returns realistic, varied data for testing systems without exposing real personal information.

6.4 → 2.3 GBGPU memory after 4-bit compression
0data sent to an external API
3Bparameters, Llama 3.2 Instruct
  • Loads Llama 3.2 3B Instruct from Hugging Face and compresses it to 4-bit with bitsandbytes to fit a free T4 GPU.
  • Wraps prompts in the model's chat template and decodes only the newly generated tokens.
  • Simple Gradio interface. The same generator produced the data for the churn analysis above.
